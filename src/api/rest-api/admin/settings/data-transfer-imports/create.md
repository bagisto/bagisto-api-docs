# Create Import

::: warning Create endpoint deferred
Creating new imports via the API is **not yet supported in v1** — multipart file upload + entity-type routing requires additional plumbing.

For now, use the admin panel (**Settings → Data Transfer → Imports**) to create imports. Once created, the API can list / get detail / delete / cancel them.

This page is a placeholder so the docs sidebar mirrors the admin sub-menu structure.
:::
